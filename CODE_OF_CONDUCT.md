# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be civil, assume good faith, and keep discussion on the technical
question. Harassment of any kind is not welcome here.

Report a problem through GitHub's private reporting on this repository. Reports
are read by the maintainer and kept confidential.
